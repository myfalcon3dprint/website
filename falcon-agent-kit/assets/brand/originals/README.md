# Falcon 3D Prints — Original Brand Assets Repository

> This directory is reserved for unmodified, high-resolution original brand vector and raster assets.

## Directory Policy

1. **Immutability**: Original files placed here must never be destructively overwritten, compressed, or resized in place.
2. **Derivative Assets**: All web-optimized derivatives (SVGs, responsive WebP images, favicons, OG images) belong in `public/brand/` or `assets/brand/processed/`.
3. **Current Status**: Awaiting upload of official logo source files. Once supplied, record their file hashes and dimensions in [`docs/brand/asset-manifest.json`](../../../docs/brand/asset-manifest.json).

## Expected Master Assets
- `falcon-logo-primary.svg` (or `.png` master)
- `falcon-logo-icon.svg` (or `.png` master)
- `falcon-logo-wordmark.svg`
- `falcon-logo-dark-background.svg`
